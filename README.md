# medical-ai-assistant
Bilingual (Arabic/English) AI medical assistant built on Altibbi's own content — RAG-grounded Q&amp;A over Altibbi articles, voice chat via ElevenLabs, medical report/image analysis with Gemini, doctor lookup, and an admin usage dashboard. Built with n8n, Supabase, Postgres, and Milvus/Zilliz.
